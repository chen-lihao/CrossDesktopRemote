## 3. Spring Boot 控制平面

项目使用 Spring Boot 4.1.0、Java 17、Gradle Groovy DSL。工程由 `start.spring.io` 生成，包含 Web MVC、WebSocket、Validation、Security、Actuator、JPA、Redis、PostgreSQL 和 Flyway。

复现命令：

```bash
./scripts/bootstrap-spring.sh
```

生成器提供 Gradle 9.5.1 Wrapper，因此应使用工程内 Wrapper，不依赖机器上的 Gradle 8.13：

```bash
./services/control-plane-java/gradlew \
  -p services/control-plane-java \
  tasks
```

已增加：

- `application-local.yaml` 和 `application-test.yaml`，连接本地 Compose 的 PostgreSQL/Redis。
- `V1__control_plane_baseline.sql`，建立 Flyway 基线表。
- 最小安全策略，只匿名放行 `/actuator/health`，其他请求默认拒绝。

已验证 `gradlew test` 成功；`SPRING_PROFILES_ACTIVE=local ... bootRun` 能连接 PostgreSQL/Redis、执行 Flyway V1，`/actuator/health` 返回 `UP`，根路径返回 `403`。这只证明控制平面基座可运行，不代表身份、设备、会话和信令 API 已实现。

用户级 `~/.gradle/init.gradle` 当前通过 Settings 级仓库、`PREFER_SETTINGS`、阿里云 Maven 和 Flutter 国内镜像解决本机网络问题。该文件会影响本机所有 Gradle 工程，只是开发机网络适配，不是仓库运行所依赖的隐式配置。

## 6. Protobuf

协议源文件位于 `proto/crossdesktop/v1/`，当前包含 common、capability、device、session、signaling 五组基础消息。生成物位于各工程的 `build/generated`，不手工修改或提交。

```bash
./scripts/generate-proto.sh
```

该脚本依次执行 Java、Dart、Rust 生成/编译和 `buf lint`。当前已验证三种语言生成结果均可编译/分析；后续协议变更还必须增加 breaking check 和新旧版本互操作测试。

## 7. 本地基础设施

`infra/deploy/compose.dev.yaml` 提供版本锁定的 PostgreSQL、Redis 和 coturn，本地默认凭据仅用于开发环境。PostgreSQL/Redis 只监听 loopback，coturn 暴露 3478 TCP/UDP 和受限 UDP relay 端口段。

```bash
./scripts/dev-up.sh
docker compose -f infra/deploy/compose.dev.yaml ps
```

当前三个容器健康。`turnserver.dev.conf` 关闭本地 TLS/DTLS，仅用于开发验证；生产环境必须使用独立密钥、短期 TURN 凭据、TLS、网络访问控制和区域化部署。
