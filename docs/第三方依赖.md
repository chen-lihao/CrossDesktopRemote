## `flutter_webrtc` 采用边界

- 只让插件处理原生媒体、WebRTC 和视频视图；禁止把原始视频帧复制到 Dart。
- Dart 只管理会话状态、SDP/ICE 和体积受限的控制消息。
- 当前包包含/引用预编译 WebRTC SDK；MIT 仅是插件本身许可证，不能替代对 libwebrtc、编解码器专利、传递依赖和二进制来源的发布审查。
- 不修改 `~/.pub-cache`。当前源码作为仓库内 fork 管理，`CROSSDESKTOP_PATCHES.md` 记录 macOS Core Image/Metal SDR 归一化、Video-Range NV12、Rec.709、iOS BT.709 Texture 渲染和诊断通知补丁。
- macOS 15+ 显式设置 `captureDynamicRange = SDR`；所有受支持 macOS 版本把原始帧经 Core Image/Metal 实际转换为 `420v`、BT.709，再传播与像素一致的 primaries/transfer/matrix 附件。
- iOS 原生 PixelBuffer 使用 Core Image 做 Range/色彩空间转换，I420 后备使用 Accelerate/vImage BT.709 Video-Range 矩阵；新增依赖均为 Apple 系统框架。
- Android 传递依赖 `audioswitch` 来自 JitPack 固定 Git commit；仓库内容过滤为 `com.github.davidliu`，正式发布前必须保存源码来源和校验信息。
- M1 结束时根据 1080p60、色彩、延迟、内存、重连和崩溃数据决定继续维护 fork、局部替换或改为自建 ScreenCaptureKit/Metal 媒体桥。
- 升级版本前必须重新运行 macOS、iOS Simulator、物理 iPad、Android 构建和 30 分钟稳定性测试。
