# CrossDesktopRemote 初版威胁模型

> 版本：v0.1
> 范围：M0 工程基线与 M1 Windows 性能原型
> 状态：设计基线，需随真实数据流和权限实现持续更新

## 1. 保护目标

- 设备身份私钥、用户凭据、MFA 状态和无人值守授权。
- 会话票据、SDP/ICE 信令、DTLS fingerprint 和权限集合。
- 屏幕、输入、剪贴板、文件、截图与录像内容。
- 控制平面业务数据、审计记录和 TURN 短期凭据。
- 高权限系统服务、更新通道和客户端二进制完整性。

## 2. 信任边界

```text
Flutter UI（普通用户权限）
    │ 窄 C ABI
Rust Core（不信任网络和文件输入）
    │ 已认证本机 IPC
平台 Worker / 高权限 Broker（最小权限）

客户端 ── HTTPS/WSS ── Java 控制平面 ── PostgreSQL/Redis
客户端 ── DTLS-SRTP/DataChannel ── P2P 或 coturn 密文中继
```

边界规则：

- Flutter 不处理原始视频帧、密钥和高权限系统操作。
- 高权限 Broker 不解析视频、图片、压缩包或复杂远端文件内容。
- Java 控制平面不解密和转码桌面媒体。
- coturn 只转发端到端加密流量，不获得会话内容密钥。

## 3. 主要威胁与控制

| ID | 威胁 | 影响 | 必须控制 | 验证门禁 |
| --- | --- | --- | --- | --- |
| T-001 | 设备密钥被复制或替换 | 无人值守设备被接管 | OS 密钥库、不可导出密钥优先、设备撤销、密钥轮换 | 密钥存储与撤销测试 |
| T-002 | 辅助码、会话票据或信令重放 | 未授权重连 | 短有效期、随机数、一次性消费、绑定双方设备和权限 | 重放与过期用例 |
| T-003 | Offer/Answer 或 ICE 被篡改 | 会话劫持、中间人 | 信令鉴权；绑定 session、设备、权限、有效期和 DTLS fingerprint | 篡改字段必须拒绝 |
| T-004 | TURN 凭据泄露或滥用 | 带宽盗用、费用与封禁 | REST 短期凭据、realm 隔离、速率/配额、区域监控 | 过期凭据和配额测试 |
| T-005 | 高权限 Agent 被利用 | 系统级控制权泄露 | Broker 最小化、IPC 双向认证、命令白名单、签名和沙箱 | IPC fuzz、越权调用测试 |
| T-006 | 文件路径穿越或符号链接逃逸 | 任意文件覆盖/泄露 | 规范化目标根、拒绝绝对路径和 `..`、安全创建、磁盘配额、SHA-256 | 恶意目录与链接用例 |
| T-007 | 剪贴板、截图、录像越权 | 隐私数据泄露 | 每项独立 scope、显式提示、方向控制、默认关闭敏感能力 | 权限矩阵测试 |
| T-008 | 日志记录敏感内容 | 凭据与用户数据泄露 | 禁止记录按键、正文、帧、文件块、token 和私钥；字段级脱敏 | 日志扫描门禁 |
| T-009 | 无界消息、队列或文件占用 | 客户端/服务端拒绝服务 | 消息大小、连接数、队列、超时、速率、磁盘和内存上限 | 过载和慢客户端测试 |
| T-010 | 媒体解析器漏洞 | 远程代码执行 | 使用受维护编解码器、媒体 Worker 降权隔离、及时升级、模糊测试 | 崩溃与畸形码流测试 |
| T-011 | 更新或依赖供应链被替换 | 全量设备受控 | 签名更新、固定版本、SBOM、来源校验、回滚保护 | 签名失败必须拒绝 |
| T-012 | 移动端权限误导或后台滥用 | 商店拒审与隐私风险 | 遵循 MediaProjection/ReplayKit，持续系统提示，不绕过授权 | 真机权限生命周期测试 |

## 4. 当前实现状态

- 已建立：窄标量 C ABI、协议主版本、Protobuf lint、默认拒绝的 Java HTTP 安全策略、本地依赖健康检查。
- 尚未建立：设备身份、MFA、会话票据、端到端权限绑定、签名更新、高权限 IPC、审计和限流。
- 本地 Compose 的默认密码和无 TLS coturn 只允许开发机使用，不得部署到共享或生产网络。
- 用户级 Gradle 国内镜像是开发机网络适配；生产构建需要可信制品代理、依赖校验和 SBOM。

## 5. 进入 M1 前的安全门禁

1. 明确 Windows Service、Session Worker、Rust Core 和 UI 的进程权限及 IPC 消息上限。
2. 对设备身份、会话票据和信令绑定形成可测试的数据结构。
3. 为输入、剪贴板、文件、截图和录像建立独立权限 scope。
4. 为 WebSocket、Redis 在线租约和 TURN 凭据设置 TTL、速率和队列上限。
5. 建立依赖许可证清单、SBOM 和高风险依赖升级流程。
6. 对所有网络/文件解析入口安排 fuzz、属性测试和恶意输入用例。
